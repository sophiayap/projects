# Projects

Small, reproducible data analysis projects in R by Sophia Yap.

## Projects

- **[Chick Weight and Feed Type](chickwts-anova.pdf):** One-way ANOVA with Tukey's HSD on the `chickwts` dataset. Feed type significantly affects chick weight (F(5, 65) = 15.37, p < 0.001).
- **[Mammal Sleep Patterns](mammal-sleep.pdf):** Visualisation of sleep duration by diet and animal order in the `msleep` dataset, using dplyr, forcats and ggplot2.
- **[Palmer Penguins](palmer-penguins.pdf):** Faceted plots and a logistic regression predicting penguin sex from bill length, flipper length and body mass.

## Tools

R, tidyverse (ggplot2, dplyr, tidyr, forcats), palmerpenguins, R Markdown
